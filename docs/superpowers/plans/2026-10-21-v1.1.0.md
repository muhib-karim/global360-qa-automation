# v1.1.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn the red E2E badge green for the right reasons and make it stay green.

**Architecture:** Test-side fix in a pure, unit-tested parser; CI-side fix in one install script plus a cache;
docs and Pages built from CI outputs.

**Tech Stack:** .NET 10, NUnit 4, Playwright 1.63.0, GitHub Actions, Allure 2.46.1.

**Spec:** `docs/superpowers/specs/2026-10-21-v1.1.0-design.md`

## Global Constraints

- No en or em dashes, no `Thread.Sleep|Task.Delay|WaitForTimeoutAsync|Force = true` in `tests/` (build guardrail).
- Actions pinned by commit SHA with the version in a comment.
- No unit test needs a browser or the network.

## Review Focus

- A runner whose culture is not English (e.g. `th-TH`, Buddhist calendar): the parser must still read the demo's
  English month names and Gregorian years. Pinned by a `[SetCulture]` unit test.
- `03/04/2026 10:00`: `m/d/Y` and `d/m/Y` both parse; the parser returns both and the window picks the real one.
- A weekday that does not match the date (`Thu Oct 21, 2026`): rejected, not silently accepted.
- A date with no time (`2026-10-21`): rejected.
- Every download host down: the install script fails after its last attempt with a clear error, it does not hang.
